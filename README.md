# Anonymous Bilingual Policy Summarization Dataset

This dataset is a bilingual collection designed for research on automatic summarization of structured public documents.

It supports both monolingual and cross-lingual summarization tasks and includes a mixture of textual documents and multimedia-based policy communications.

The dataset is intended for research in natural language processing, including document summarization, multilingual alignment, and structured information extraction.

---

## 📂 Dataset Structure
```
├── Documents/     # 1,300+ pre-processed official documents
├── dataset.csv    # Text summarization dataset
├── videos.csv     # Metadata and transcripts for related communications
└── README.md
```

## 📄 dataset.csv (Text Summarization Data)

This file contains multi-stage summarization outputs for each document:

- **File Name**: Anonymized document identifier  
- **Model Output 1**: Initial summary generated by a large language model  
- **Model Output 2**: Refined summary produced by a second-stage model after human review  
- **Vietnamese Summary**: Final human-verified summary in Vietnamese  
- **English Summary**: Machine-translated version of the Vietnamese summary, followed by human verification to ensure consistency and semantic equivalence  

---
## 📊 Dataset Statistics

- Number of documents: 1,300+ official texts
- Number of videos: 100+ communications
- Language coverage: Vietnamese and English
- Human verification: Final summaries reviewed for quality and consistency

---

## 🧠 Data Construction Pipeline

The dataset is constructed using a multi-stage processing pipeline:

1. Raw document collection and extraction
2. Automatic summarization using large-scale language models
3. Human review and correction of initial summaries
4. Secondary refinement using an additional model
5. Machine translation for cross-lingual alignment
6. Human verification of translated outputs to ensure semantic consistency
